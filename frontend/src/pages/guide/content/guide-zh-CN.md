## {#welcome} 欢迎使用 Voxis Source-Available

Voxis Source-Available 可以把音频转成可搜索的转录文本和 AI 摘要。您还可以导出成果，并通过 API 或 MCP 连接其他工具。

Voxis 运行在您所在机构自己的服务器上。生成转录时，服务器会使用机构的 Speechmatics 账户，把音频发送到云端转录服务 Speechmatics。发送时使用通用文件名，而不是您的原始文件名。之后，Voxis 会请求 Speechmatics 删除该任务。

摘要由机构自行运行的 Gemma AI 模型生成。您的转录文本只会发送给这个模型。

Voxis 会加密其存储的音频、转录文本和摘要。文件名、标题等文件信息以及账户信息不在此加密范围内。服务器的管理人员能够接触到您的数据，因此请只在信任他们的情况下使用 Voxis。

## {#sign-in} 登录和账户安全

此安装使用捆绑的 Keycloak 域 `voxis-oss` 和 `voxis-oss-web` 客户端。登录使用 PKCE S256，因此需要 HTTPS 或 localhost。

- 请让管理员为您创建账户并开通 Voxis 访问权限。
- 如果您能登录，但看到请您联系管理员的提示，说明您的账户尚未获得访问权限。管理员可以在 Keycloak 中开通。
- 请在 Keycloak 账户控制台中修改密码和多因素身份验证。
- Voxis Source-Available 不提供自助注册、社交登录、电子邮件验证或账户删除功能。如有需要，请联系管理员。

## {#upload} 上传音频

从仪表板或侧边栏选择**上传**。选择音频文件，等待扫描和加密存储完成，然后从文件阅读器开始转录。

在资料库中，您可以编辑文件详情、打开阅读器、搜索音频和转录文本，以及删除您拥有的媒体。搜索转录内容时，Voxis 会按有限页面检查已完成的转录。显示按钮时，请使用**加载更多转录匹配项**继续搜索较早完成的转录。

删除文件是永久性的。服务器上的音频、转录文本、摘要，以及文件名、标题和描述都会被删除，且无法撤销。机构现有备份中的副本会一直保留，直到这些备份被删除。

Speechmatics Melia 1 不提供自定义词典和词汇包。

## {#record} 录音和恢复

选择**录音**，在浏览器中录制麦克风或支持的设备音频。页面关闭或网络中断后，您返回时录音器会提供恢复中断会话的选项。

录音片段在上传完成前会保存在此浏览器中。这些片段已加密，但密钥也保存在同一浏览器中，因此只能防止随意查看。您退出登录时，Voxis 会清除这些片段；如果还有片段尚未上传，会先提醒您。其他人在此浏览器登录时，这些片段也会被清除。在共用电脑上，请等上传完成后再退出登录。

如果管理员设置了录音保留期限，浏览器录音的音频会在期限到期后被永久删除，转录文本和摘要会保留。

Voxis Source-Available 支持标准录音，不提供特权录音。

如果转录失败，其活动卡片会显示安全的失败类别。请打开该项目，必要时检查服务提供商设置，然后重试。

## {#summaries} 阅读摘要和导出

阅读器显示转录文本、说话人编辑和可用的专业摘要格式。本地 Gemma 模型根据配置的公开提示词集生成摘要。高风险摘要配置默认关闭，需由管理员开启。

可导出 PDF、DOCX 和 JSON。PDF 导出无法可靠支持中文、日文或韩文；请对这些文字使用 DOCX 或 JSON。BAP 导出需主动启用，除非操作员启用，否则默认关闭。

如需保存自己的成果副本，请下载音频，并导出每份转录文本和摘要。您也可以使用 API 密钥或 MCP 工具批量获取。

## {#admin} 管理、API 和 MCP

管理员可以检查运行状态、设置录音保留期限，并编辑公开的 Gemma 展示提示词。服务器报告时，管理区域会显示服务模型名称、运行时、修订版、量化方式和可用的使用数据。此版本不强制执行存储配额。

API 密钥和 MCP 工具遵循与应用相同的组织和所有权规则。请勿将密钥放入浏览器代码，只与您信任的工具共享。密钥所有者被停用或失去访问权限后，约一分钟内密钥即失效。
