## Keycloak vulnerability review

The runtime copies the Keycloak 26.7.5 distribution from
`quay.io/keycloak/keycloak@sha256:6529db34610ce6328824218dce3bbe55c4ba4757bc5c8a09b5a4c746e28b6e9d`
onto the pinned Linux amd64 Temurin Noble JRE
`eclipse-temurin@sha256:7fd597bf48c8bb13a7a3fb227f8366dec0423f78775d4b4f7e30409204af8627`.
The upstream `26.7.5` source tag resolves to
`44299f39868f252ea02236134618c8c5c70a6e9d`. The Temurin container recipe
uses Ubuntu 24.04 and installs the signed Temurin JRE; it does not make the
Ubuntu layers or their package notices Apache-licensed.

A VEX-free Trivy 0.74.0 scan of derived image
`sha256:a6250ea769b3acda9a52dacedb4c25445a4a68f1c6cef6c2035b63d65bfcd201`
reported one HIGH or CRITICAL result: mssql-jdbc for CVE-2025-59250, a
version-normalization match on the fixed `13.2.1.jre11` build. It reported no
HIGH or CRITICAL operating-system package result. The final security job binds
its one reviewed statement to that exact Maven PURL in the derived image SBOM
and still fails every other HIGH or CRITICAL finding.

The detailed package, advisory, source-path, configuration, and guard evidence
is in [the runtime security record](infra/oss/security/README.md). A changed
image, runtime Dockerfile, Compose file, realm, or proxy configuration requires
a new scan and review. This is image and identity-runtime evidence; it does not
establish security for the rest of the application. This source release does
not distribute the Keycloak image.
## Model, binary, and service limits

The intended local summary model is `google/gemma-4-12B-it` or the official `google/gemma-4-12B-it-qat-q4_0-gguf` variant selected by the operator. Those selected Gemma 4 artifacts declare Apache-2.0. The 26B-A4B model is a separate comparison candidate. The model file, runtime, revision, quantization, hardware, and license must be recorded for each release candidate.

The first intended configuration sends audio to Speechmatics cloud with the installation owner's credentials. Speechmatics has separately arranged on-premises offerings, but Voxis Source-Available does not yet verify that path. No term in this document grants access to Speechmatics, model weights, registries, hosting, or other third-party services.
